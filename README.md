# Exploratory Analysis of Gene Expression Data

## Overview
This project analyzes gene expression data to identify differences between two groups based on a response variable.

## Objectives
- Compare gene expression between two groups
- Identify differentially expressed genes
- Visualize key differences

## Methods
- Data preprocessing and cleaning
- Group separation based on response
- Mean-based comparison of gene expression
- Visualization using bar plots

## Key Findings
- Genes such as MALAT1 and XIST showed higher expression in one group
- Genes like MUC16 and RNF213 were higher in the other group
- Results indicate distinct molecular patterns between groups

## Tools Used
- Python
- pandas
- matplotlib

## Note
This is an exploratory analysis based on mean differences and does not include statistical validation.
